QUICK START

# 1. Install package
pip install doescap

# 2. Synchronous solving in 1 line
from doescap import solve_captcha

token = solve_captcha("4c672d35-0701-42b2-88c3-78380b0db560")
print(f"Verified Token: {token}")

# 3. Asynchronous solving with asyncio
import asyncio
from doescap import async_solve_captcha

async def main():
    token = await async_solve_captcha("4c672d35-0701-42b2-88c3-78380b0db560")
    print(f"Async Token: {token}")

asyncio.run(main())

DoesCap starts a local ThreadingHTTPServer, automatically opens your device browser, receives the solved token via POST /solve, and returns a string-compatible SolveResult (or None if cancelled/timed out).

INSTALLATION

STANDARD INSTALLATION

Python 3.8+ required with zero external dependencies for standard Direct In-Browser mode: 

pip install doescap
HEADLESS SCREENCAST EXTRA (OPTIONAL)

Installs websocket-client>=1.6.0 required for Chrome DevTools Protocol (CDP) screencast mode: 

pip install "doescap[screencast]"
